{% docs airport_type %}

The type of the airport. Allowed values are "balloonport", "closed_airport", "heliport", "large_airport", "medium_airport", "seaplane_base", and "small_airport".

| Airport type | Description |
| --- | --- |
| large_airport | Land airport with scheduled major airline service with millions of passengers/year, or major military base. |
| medium_airport | Land airport with scheduled regional airline service, or regular general aviation or military traffic. |
| small_airport | Land airport with little or no scheduled service, light general aviation traffic. |
| heliport | Helicopter pad(s) with no runways available for fixed-wing aircraft. |
| seaplane_base | Docking/fueling area for seaplanes, with no facilities for land aircraft. |
| balloonport | Area for launching hot-air balloons. |
| closed | Any type of airport that's no longer operational. |
